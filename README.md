# First Contribution Hub

Welcome to First Contribution Hub!

This repository is created for beginners who want to make
their first open-source contribution.

## How to Contribute

1. Check the Issues tab.
2. Find an issue labelled `good first issue`.
3. Comment on the issue before starting.
4. Fork this repository.
5. Create a new branch.
6. Make your changes.
7. Open a Pull Request.
8. Wait for review.

## Contribution Types

- Java
- DSA
- Documentation
- Bug Fixes
- Tests
- Examples
