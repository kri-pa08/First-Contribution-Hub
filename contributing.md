# Contributing Guide

Thank you for wanting to contribute to First Contribution Hub! 

This repository is designed to help beginners make their first open-source contribution.

## How to Contribute

1. Check the Issues tab.
2. Find an issue labelled `good first issue`.
3. Comment on the issue before starting.
4. Fork this repository.
5. Create a new branch.
6. Make your changes.
7. Push your branch to GitHub.
8. Open a Pull Request.
9. Wait for review.

## Contribution Rules

- Keep your changes simple and relevant to the issue.
- Follow the existing project structure.
- Write clear and readable code.
- Do not submit spam or unnecessary changes.
- One issue should generally correspond to one focused Pull Request.

## Need Help?

If you are stuck, feel free to ask questions in the issue discussion.

Happy contributing!
